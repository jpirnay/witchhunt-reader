# Writing Modes Step 2, PR 3b: The Font Manager's Indic Families — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or
> superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The Font Manager offers Noto Sans and Noto Serif for each of the ten Indic scripts, each merged with Noto's
Latin and left out of "Download all", and an Indic book uses an installed family of its script by itself, as a CJK
book does.

**Architecture:**
- **The fonts.** The merge recipe of PR 2's item 3 moves into the repo's font build:
  - `lib/EpdFont/scripts/merge_noto_latin.py` does the merge and its two HarfBuzz checks;
  - `build-sd-fonts.py` gains a `format: ttf` path that calls it;
  - `sd-fonts.yaml` pins the 20 families' sources.
- **The output** is 40 TrueType files under `assets/sd-fonts/`, with the manifests regenerated by `--manifest`.
- **The engine** is checked against HarfBuzz on every shipped file, at two sizes, through the `CPac` the install
  writes.
- **The reader:**
  - a book whose language is written in an Indic script selects `NotoSans<Script>` or `NotoSerif<Script>` when the
    reader's font lacks the script;
  - this goes through the CJK path of `SdCardFontSystem::selectLanguageFamily`;
  - the language-to-script table lives in `LanguageTag.h`, the one table `TypographyProfile` reads too.

**Tech Stack:**
- Python 3 with fontTools 4.63.0 and uharfbuzz 0.56.2 (HarfBuzz 14.5.0) for the build;
- C++20 (firmware and host gtest suite);
- PlatformIO for the X3.

**Spec:** `docs/superpowers/specs/2026-11-02-writing-modes-step2-design.md`:
- decision 6, as refined on 2026-11-02;
- "Font Manager families" in "How shaping runs";
- the Constraints.

The measurements of the recipe are `docs/superpowers/specs/2026-11-02-writing-modes-step2-measurements.md`, "Item 3:
the merged fonts of decision 6". The PR 3 plan's scope check (`docs/superpowers/plans/2026-11-05-writing-modes-step2-pr3.md`)
moved this work here.

**The maintainer's rulings for this PR (2026-11-06):**
- An Indic book picks an installed Noto family of its script automatically, as CJK books do.
- The X4 is not required (PR 3's ruling, kept).

## Global Constraints

From the design, verbatim:
- **The 20 families:** "Noto Sans and Noto Serif for each of the ten Indic scripts (20, PR 3): Devanagari, Bengali,
  Gurmukhi, Gujarati, Oriya, Tamil, Telugu, Kannada, Malayalam, Sinhala". The family names are `NotoSans<Script>` and
  `NotoSerif<Script>` with those ten words, and the files are `<Family>/<Family>-Regular.ttf` and `-Bold.ttf`
  ("regular and bold files; italic is the engine's slant").
- **The recipe** ("decision 6, refined 2026-11-02"):
  - "the script font's cmap loses A-Z and a-z. Its glyphs stay, so its glyph IDs and its own shaping do not change";
  - "Noto's Latin is a `fontTools.subset` of U+0020-007E, U+00A0-024F, U+2000-206F, U+20A0-20CF, U+2122 and U+FFFD,
    less every code point the script font still maps";
  - "`fontTools.merge`, the script font first (its glyph order, names and cmap win), with `vhea` and `vmtx` dropped";
  - "a Sans with Noto Sans, a Serif ... with Noto Serif".
- **The checks:** "the merge is checked by the HarfBuzz oracle in two ways. The merged font must shape the script's
  corpus as the script's own font does. Each Latin line, restricted to its runs of A-Z and a-z, must shape as in Noto
  Sans or Serif itself."
- **The Font Manager:** "made by `build-sd-fonts.py` with the pinned fontTools, `inDownloadAll: false`, the manifest
  regenerated with `--manifest` (the CJK re-cut trap)".
- **The engine bar:** "The engine's output matches HarfBuzz 14.5 glyph for glyph on the oracle corpus (upstream's bar:
  0 differences), for every font PR 3 and PR 4 ship, at two sizes, and with `CPac` from the install."
- **Goldens:** "Every Latin, CJK and Hebrew golden stays byte-identical." This PR changes no layout, so every golden
  stays byte-identical.

From the measurements and the repo:
- **Pinned tools:** fontTools 4.63.0 and uharfbuzz 0.56.2, whose `version_string()` is 14.5.0.
- **Pinned sources:** the 44 unhinted files of `notofonts/notofonts.github.io` at
  `5c82cef0a8f08806f932062e18c02be62be278f0` (`fonts/<F>/unhinted/ttf/<F>-<S>.ttf`): the 40 script files and Noto
  Sans and Noto Serif Regular and Bold. Each is pinned by the sha256 in the measurements' "Fonts" table. A source
  whose hash differs fails the build, as `download_font` already does.
- **Determinism:** the build writes the same bytes on every run (`TTFont(..., recalcTimestamp=False)`, as
  `cjk_subset.py` does).
- **The oracle's two sizes:** `Scale::set(2133, 33, upem)` (item 1's) and `Scale::set(1195, 19, upem)`. In
  `compare_harfbuzz.py` that is scale 2133, ppem 33 and scale 1195, ppem 19.
- **Licences:** the Noto fonts are OFL. `assets/sd-fonts/OFL.txt` carries each new font's copyright line.
- **No literal bidi control characters** (U+200E/F, U+202A-202E, U+2066-2069, U+061C) **and no literal ZWJ or ZWNJ**
  in sources or commit messages.
- **Downloads are untrusted data:** each goes into its own new scratch directory, and Python that reads them runs
  with `-I`.
