# Design records

These are design records for shipped features, cited from code comments by path (and, for the list scheme and the CJK fonts, `cjk-ttf-fonts.md`, by section number). They describe why the code is shaped as it is; the code is the authority on what it does now.
Open work lives in `docs/future_work/`.

Code in `lib/EpdFont/ttf/` cites `cjk-ttf-fonts.md` as "spec N.N"; older comments there cite the TTF engine spec,
`docs/superpowers/specs/2026-10-13-ttf-fonts-design.md`.
